# Spurwerk 0.2: модель

## Не T9

T9 или n-граммная модель отвечает: «какой токен вероятен после текущих токенов?» Spurwerk отвечает на другую последовательность вопросов:

1. Что за предмет введён?
2. Какие его свойства нельзя потерять?
3. Какие связи с целановским миром имеют исследовательское основание?
4. Какое противоречие возникает?
5. Как предмет движется к `Du`, свидетельствует или не достигает адресата?
6. Что остаётся после преобразования?
7. Как это событие меняет дыхание и рисунок строки?

Языковой слой работает последним и не имеет права переписывать внутренний план.

## Поток данных

```text
input
  → semantic passport
  → typed claim retrieval
  → semantic plan
  → word-conditioned form
  → 36 language realizations
  → semantic/form/novelty scoring
  → selected poem + trace
```

### 1. Semantic passport

`resolver.mjs` ищет точные слова и части немецких композитов. После уверенного совпадения он может добавить только заранее объявленные мосты — например, `sphere → shell` или `machine → hearing`. Буквенное сходство не используется как уверенное понимание.

Паспорт содержит собственные свойства предмета, уверенность, шесть параметров формы и доступный корпусный контекст. Неизвестный ввод становится `unknown`, а не случайным «камнем».

### 2. Typed claims

Исследовательское утверждение имеет структуру:

```json
{
  "id": "c002",
  "from": "stone",
  "relation": "holds_tension",
  "to": "flight",
  "operation": "inversion",
  "sources": ["user-seven"]
}
```

Граф хранит не соседство, а направленное действие. `stone → silence` и `stone carries death-light while siding with Du` — принципиально разные знания.

### 3. Semantic planner

Планировщик создаёт композицию, а не случайное блуждание. Обязательны внимание к предмету, преобразование, встречная сила, обращение и остаток. У каждой исследовательской связи есть `claimId`; синтетические переходы маркируются как `planner`.

План проверяется принципами личности: внимание, автономность предмета, встреча, незавершённая память, продуктивное молчание, отказ от дешёвого искупления, внутренняя композиция и открытость.

### 4. Word-conditioned form

Форма начинается с позднего корпуса: 9 строк по 3 слова. Затем слово воздействует через независимые параметры:

- `gravity` сужает строку и сокращает движение;
- `compression` удаляет поясняющие звенья;
- `fragmentation` увеличивает вероятность разрыва;
- `pause` вставляет пустой интервал;
- `motion` удлиняет траекторию;
- `address` усиливает необходимость `Du`.

Корпусная длина строки понятия примешивается слабее и не подменяет интерпретацию.

### 5. Realizer

Русская и немецкая микро-грамматика реализует **отношения**, а не заполняет один универсальный шаблон:

```text
sides_with       → Stein, auf deiner Seite.
ruptures_into    → Hülle reißt — in Spur.
keeps_unfinished → Eingedenken schließt nicht ab: Vergangenes.
```

Переносы создаются после смысловой строки и сохраняют связь с породившим событием.

### 6. Candidate selection

Из 36 вариантов выбирается кандидат, который:

- сохраняет ввод;
- реализует обязательные стадии;
- содержит обращение;
- ближе к назначенной форме;
- использует исследовательские связи;
- не повторяет одни и те же слова слишком часто;
- не производит ложного закрытия;
- не совпадает с четырёхсловными фрагментами корпуса.

## Что ещё нужно для 0.3

1. Расширить нынешние 60 утверждений до 200–300 с точными страницами и степенью уверенности.
2. Добавить немецкую морфологию и WordNet/Wiktionary-паспорт физических свойств.
3. Подключить локальные multilingual embeddings только как источник кандидатов-мостов.
4. Ввести экспертную оценку маршрутов и регрессионный набор сложных слов.
5. Различать периоды Целана и позволить выбрать `Sprachgitter`, `Lichtzwang` или `Schneepart`.
6. Выучить условную форму из полного критически выверенного корпуса, не смешивая OCR и переводы.
